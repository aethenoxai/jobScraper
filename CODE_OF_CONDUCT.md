# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and help keep this a welcoming place for people of every background and experience level. Harassment, personal attacks and publishing others' private information are not tolerated.

Report unacceptable behaviour privately to the maintainers through GitHub (Security → Report a vulnerability works for private messages too, or contact a maintainer directly). Reports are handled confidentially, and maintainers may remove contributions or block participants who break these rules.
